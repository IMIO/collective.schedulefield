# collective.schedulefield

[![Tests](https://github.com/IMIO/collective.schedulefield/actions/workflows/test-matrix.yml/badge.svg)](https://github.com/IMIO/collective.schedulefield/actions/workflows/test-matrix.yml)
[![Meta](https://github.com/IMIO/collective.schedulefield/actions/workflows/meta.yml/badge.svg)](https://github.com/IMIO/collective.schedulefield/actions/workflows/meta.yml)

Schedule behaviors for Plone content types.

## Features

- Schedule or multi-schedule (with date ranges) behaviors to define schedules (morning / afternoon / comment) by day of week
- Exceptional closure behavior to define closing days

## Compatibility

* Versions **2.x** support **Plone 6.2**, on Python 3.10 to 3.14.
* Versions **1.x** are developed for **Plone 6.0 and 6.1**.
* Versions **0.x** are developed for **Plone 4 & Plone 5**.

  > Please note that they do not provide the full functionality (no multi-schedules,
  > no exceptional closures, no RESTAPI serializer).

## Installation

Add `collective.schedulefield` to the dependencies of your project
(`pyproject.toml`, or `requirements.txt` with the Plone constraints), install
it, restart Plone and activate the add-on in *Site Setup* > *Add-ons*. Then
enable the behaviors you need on your content types.

## Development

Requires [uv](https://docs.astral.sh/uv/). This installs Plone 6.2.3 on Python
3.14 in `.venv` (set `PLONE_VERSION` for another Plone 6.2 release) and the prek
git hook:

```shell
make install
make start          # Plone on http://localhost:8080 (admin / admin)
```

Create a Classic UI site from the browser, then activate collective.schedulefield.

### Tests

Tests run through tox, as the CI does:

```shell
make test                                   # Plone 6.2.3
uvx --with tox-uv tox -e py310-plone62      # one Python version
make test-all                               # lint, every Python version, dependencies
```

Without tox:

```shell
.venv/bin/pytest tests
```

### Lint

```shell
make check          # format then lint (pyupgrade, isort, black, zpretty, flake8...)
```

### Translations

```shell
make i18n           # rebuild the collective.schedulefield catalogs
```

`.editorconfig`, `.flake8`, `.gitignore`, `.pre-commit-config.yaml`, `tox.ini`,
`.github/` and the tool sections of `pyproject.toml` are generated by
[plone.meta](https://github.com/plone/meta): change `.meta.toml`, then run
`uvx --from plone.meta==2.12.0 config-package --no-commit --branch current .`.
